# PassGen 实现说明

更新日期：2026-11-03。当前包版本为0.1.1，使用Rust + Slint；包含符号集、About和透明窗口修正及新应用图标。用户已在无开发工具的Windows10／11环境测试已发布版本并反馈未发现问题，Linux／macOS尚待实机验证。

使用方法见 [README](../README.md)，构建与检查见 [开发与验证](development.md)，设计演变见 [设计历史](design-history.md)。

## 代码结构

| 位置 | 职责 |
| --- | --- |
| `src/core/mod.rs` | 字符集、参数校验、系统随机源、拒绝采样及核心测试；不依赖 UI、文件或网络 |
| `src/app.rs` | 模式、独立长度、字符选择、语言、密码生命周期、事件及设置保存调度 |
| `src/motion.rs` | 统一驱动页面内容和窗口高度，支持中断后从当前位置继续 |
| `src/chrome.rs` | 按 DPI 生成圆角、标题栏底色和投影，缓存为九宫格纹理 |
| `src/platform/instance.rs` | Windows单实例锁、窗口标记与固定唤起消息；早于设置及UI初始化 |
| `src/platform/windows_startup.rs` | 仅启动期间隐藏未完成的原生窗口，完整首帧后揭示并移除线程局部钩子 |
| `src/platform/clipboard.rs` | 仅在用户主动复制时访问系统剪贴板 |
| `src/platform/settings.rs` | 专用设置格式、校验、本机路径和文件原子替换 |
| `src/platform/window.rs` | 原生窗口按钮、拖动缩放、宽度适配及启动／关闭位置 |
| `src/platform/windows_chrome.rs` | Windows逐像素透明卡片及可穿透的附属投影窗口，事件驱动呈现 |
| `src/platform/project.rs` | 用户主动点击时通过系统默认浏览器打开固定仓库地址 |
| `ui/app-window.slint` | Random、PIN、About 及中英文布局 |
| `ui/components.slint` | 通用按钮、标题栏按钮、长度输入、滑块及键盘操作 |
| `ui/theme.slint` | 原版蓝白配色 |
| `ui/window-chrome.slint` | 复用九宫格外观，伸缩时不重新生成投影 |
| `assets/` | 构建时嵌入的图标、字体及许可 |
| `build.rs` | 编译 Slint，调用 Windows SDK 资源编译器嵌入 EXE 图标 |
| `src/qa.rs` | 仅调试构建启用的示例界面、设置重启及窗口位置检查 |

Slint 固定为 1.18.1，使用 winit 与软件渲染器，不引入 WebView。原生窗口适配使用 `unstable-winit-030`，升级 Slint 时需复核该接口。

## 密码生成与交互

| 选项 | 范围与默认值 |
| --- | --- |
| Random 长度 | 4–64，默认 20 |
| PIN 长度 | 4–12，默认 6 |
| Random 字符类型 | `a-z`、`A-Z`、`0-9`、`~!@#$%^&*()_+`，默认全部选中，至少保留一种 |
| PIN 字符类型 | 仅数字 |
| 初始语言与模式 | 无有效设置时为简体中文、Random |

生成核心使用 `getrandom` 获取系统密码学安全随机字节，通过拒绝采样消除取模偏差。结果从选中集合的并集中均匀采样，不强制每个选中类型至少出现一次。

特殊符号按钮的 `!@#$` 为缩略标签，实际集合为上述13个ASCII符号；中英文无障碍名称使用核心中的同一完整集合。内嵌字体已包含所有这些符号，无需依赖系统字体补齐。已发布v0.1.0仍只使用4个符号，v0.1.1已包含扩展。

修改有效参数或点击结果框都会清除上一结果和复制反馈，再生成密码。结果框支持鼠标、空格和回车；默认白底，悬停与按下为 `#EAF2FF`，过渡 140ms。下方只有整行复制按钮。

鼠标在长度滑动条的30px高区域内时，纵向滚轮每个事件向上增加1位、向下减少1位。通过同一个`length-changed`回调更新长度、重新生成及记忆选项；到达当前模式上下限时不重新生成。横向滚轮与滑动条外的事件不修改长度，About打开时禁用滑动条。

不完整或越界的长度输入在提交或失焦时恢复上一有效值。展示字符串每 32 个字符插入换行，并允许界面继续折行；复制使用未插入换行的核心结果。

菜单进入同语言 About；返回进入 Random。原先已在 Random 时保留当前结果，从 PIN 返回时按 Random 设置生成。About 的版本来自 Cargo，设计稿中的 1.0 只是展示值；已移除“检查更新”占位。语言选择器下方同一行显示`技术方案 Rust + Slint / 版本 0.1.0 / GitHub`及对应英文，卡片仍高150px。GitHub为蓝色按钮，鼠标或键盘激活时通过系统默认浏览器打开`https://github.com/xinvii/PassGen`；Windows使用ShellExecuteW，应用没有HTTP请求或后台更新检查。

## Windows启动与单实例

启动最先获取当前登录会话的`Local\PassGen.App.830C27CE`命名互斥量。已有实例时，新进程在读取设置、初始化Slint及生成密码之前退出；只查找带有本应用标记的主窗口，发送固定的唤起消息。原进程恢复最小化并请求前台显示，不接受来自新进程的命令、配置或密码数据。没有后台监听线程、端口、轮询或锁文件；正常退出及崩溃时系统都会关闭互斥量句柄。预览使用独立的`PassGen.Preview`命名空间，避免测试唤起真实用户窗口。Linux／macOS的单实例仍待实现与验证。

Windows原生窗口会先经历创建、DPI及布局调整。启动阶段安装仅属于UI线程的`WH_CALLWNDPROC`钩子，在主窗口首次`WM_SHOWWINDOW`之前设置DWM cloak；此时Slint可正常完成绘制和系统尺寸事件，桌面不显示中间画面。待选项恢复、实际DPI、窗口尺寸与完整逐像素画面一致后，计算首次位置并提交画面，再取消cloak、显示投影。随后立即移除启动钩子；后续页面切换不再隐藏整张窗口，不增加延时等待或持续定时器。设置和位置检查也从真正完成首帧后启动。

## 选项记忆

Windows 默认路径为 `%LOCALAPPDATA%\PassGen\settings.json`；缺少该环境变量时回退到用户目录的 `AppData/Local`。首次保存选项或正常关闭后创建文件。

配置示例仅含非敏感选项：

```json
{
  "version": 1,
  "language": "zh-CN",
  "mode": "random",
  "random_length": 20,
  "pin_length": 6,
  "character_types": [true, true, true, true]
}
```

`language` 支持 `zh-CN`／`en`，`mode` 支持 `random`／`pin`。字符数组依次对应小写、大写、数字和特殊符号。

关闭后还会保存可选字段 `"window_position": {"x": 80, "y": 90}`，记录兼容旧版36px留白的规范化物理坐标；多显示器坐标可以为负数。当前留白不同于旧版，启动时按当前DPI解码为原生窗口位置，退出时反向编码，因此同一DPI下可见卡片不会因留白缩小而跳位。此字段不直接等于新版客户区左上角，配置结构不变。旧配置没有此字段时首次居中，配置版本仍为1。位置字段缺失或格式无效时只忽略位置，不丢弃其他有效选项。

- 只序列化专用 `Settings`，不序列化应用 `State`、密码、About 页面、无效输入或复制反馈。
- 有效选项变化后使用 400ms 单次定时器合并写入；恢复到已保存的设置会取消待写入内容。移动事件仅更新内存中的位置；正常退出前读取最后正常窗口位置并同步补写，空闲时不轮询。
- 在同目录创建临时文件，写入并同步后原子替换。`serde`／`serde_json` 处理配置格式，`tempfile` 处理临时文件。
- 最多读取 8KiB。文件缺失、损坏或版本未知时使用默认设置；越界长度和全部取消的字符选择恢复对应默认值。
- 保存失败时显示本地化提示；错误信息不包含密码或配置原文。正常退出补写失败会返回失败状态。
- 启动时按恢复的模式、语言及长度初始化动画起点与窗口高度，再生成新密码。

## 窗口、字体与动画

| 项目 | 当前规范 |
| --- | --- |
| 可见窗口 | 宽 350px，圆角 19px，标题栏 30px |
| 外框 | `#DCE1EA`，100%不透明度，1px内描边，不占布局空间 |
| 默认页面高度 | Random 263px、PIN 233px、About 150px；长密码及错误提示按需增高 |
| 投影空间 | 左／右22px、上16px、下28px；默认Random客户区394 × 307px，PIN／About为394 × 277／194px |
| 内容 | 四周 10px，内容宽 330px，主要间距 10px |
| 结果框／复制按钮 | 默认高 41px／30px，均占满内容宽度 |
| 标题栏控制 | 最小化、关闭各 44 × 30px，间隔 1px，线宽 1.7px；关闭图标 12 × 12px |
| 长度控制 | 左侧额外10px留白，默认滑动条267 × 30px、轨道2px、滑块16px；与41px宽输入间隔12px |
| 模式选中背景 | 与按钮等宽，默认156 × 30px，两侧保留6px |
| 语言选择器 | 198 × 42px，两个按钮均宽90px、高30px、文字16px |
| 动画 | 模式 280ms、About 300ms、语言 220ms、按钮反馈 140ms |

投影空间属于应用透明客户区，并非Windows额外添加的可见边框。当前8位alpha实测，100%／125%缩放下四边纯透明条带各2物理px，150%／200%下各3px；圆角附近更大。新留白保留原有可见阴影，卷积另保留向下偏移所需的上方采样行，避免截掉顶部模糊尾部。

Windows将主卡片外的alpha设为0，投影由`WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`附属窗口承载，因此阴影及纯透明区都可将点击交给下层应用。主窗口不设置整窗穿透，不使用硬窗口区域裁切。每次实际重绘后提交完整Slint画面，避免缩放、切页留下旧内容；先比较画面与原生窗口尺寸，跳过落后的帧，避免旧尺寸覆盖新的窗口请求。呈现随绘制、移动、缩放、焦点或DPI事件更新，单次定时器合并同一批事件，空闲停止；投影仅在几何或DPI变化时重新铺贴，九宫格只在启动或DPI变化时生成。当前显示DIB是必要的UI内存，复用并在覆盖、替换及退出时尽力清理，临时快照提交后尽力清理，不保存到文件。

首次使用默认 Random 时可见高度为 263px；恢复设置时直接使用对应页面高度。页面动画保持原生窗口左上角及卡片顶部固定，白色卡片持续不透明。使用一个短时动画时钟，完成后停止，连续切换从当前进度继续。

原生拖动会进入Windows嵌套消息循环，单靠Slint延迟呈现可能让窗口内容、缓存的逐像素卡片和附属投影位置错开。`windows_chrome.rs`使用仅当前UI线程的`WH_CALLWNDPROCRET`钩子，在主窗口处理完`WM_WINDOWPOSCHANGED`后立即用位置更新移动缓存画面，并同步投影窗口。它不接管原窗口过程，不重新生成像素或调整尺寸；重入保护避免位置更新递归触发自身，退出／原生呈现回退前移除钩子并清除指针。完整画面仍在正常绘制时合并提交，无新增定时轮询。

未保存位置时，按初始窗口实际尺寸在主显示器的屏幕矩形中居中。之后恢复正常关闭的位置；最小化和最大化坐标不会覆盖最后正常位置。启动时选择与卡片相交最多的显示器并将卡片移回可见范围；原显示器断开、旧位置完全不可见时回到主显示器居中。只在启动时定位，页面高度动画不会重新居中；不保存窗口大小。

圆角与双层投影由 `src/chrome.rs` 按 DPI 生成抗锯齿 RGBA 九宫格，只在启动或 DPI 变化时重新生成。窗口伸缩复用纹理，不叠加 DWM 硬裁切。拖动缩放区域位于可见卡片边界。

投影与 Figma 原生导出一致：环境层黑色 18%、偏移 y=6px、sigma=9px；接触层黑色 8%、偏移 y=2px、sigma=3px。对圆角覆盖率做高斯卷积后叠加，不能用距离高斯的峰值替代模糊轮廓，否则边缘会过黑。固定角保留圆角加三倍 sigma 的范围，确保伸缩只拉长平直边缘。

1px内描边使用同一圆角的外覆盖率减去内缩覆盖率生成，按DPI缩放，并保留外侧透明度与投影。最小化悬停底色向下留出1px，关闭遮罩使用内缩1px、18px内圆角，避免覆盖外框；按钮命中区域保持44 × 30px。

标题按实际字宽布局，之后留 4px 放置 16px 菜单／返回图标。菜单没有悬停底色；最小化使用灰底，关闭使用红底白图标并贴合右上圆角。全部控件不再绘制键盘焦点框，包括模式／字符／复制按钮、结果框、语言选择器、GitHub、长度滑块及输入框。Tab／Shift+Tab与回车／空格、滑块方向键、输入光标及失焦提交继续有效。正常窗口和结果框描边、无效长度的红色校验框不受影响。

中英文统一使用内嵌 Noto Sans SC。标题栏PassGen为12px Bold 700，使用额外的6码位、3,800字节静态子集，使主要竖笔画约1.77px，与1.7px关闭图标协调；正文保持Regular 400。正文子集为172个码位、37,228字节，增加文案需同步更新。标题按字形实际宽度布局，之后保留4px放置菜单／返回图标。窗口与EXE图标来自Figma的Page icon；资源细节及字体许可见 [assets/README.md](../assets/README.md)。

## 隐私与验证边界

应用运行时不联网，不增加遥测、密码历史或后台剪贴板监控。设置文件仅保存上述选项；生成核心不调用文件、网络或日志接口。随机源失败时显示错误，不返回示例密码或降级到普通伪随机数。

核心密码与随机缓冲区使用 `Zeroizing` 尽力清理；Slint 字符串和系统剪贴板的所有副本无法保证全部擦除。复制只由用户主动触发。

调试示例源仅在明确选择预览时启用，窗口标题带 `[UI preview]`。截图、设置重启和位置检查还要求 `ui-qa` 功能；正式构建排除这些入口。常规预览不读写真实设置，重启和位置检查仅使用明确指定的隔离文件。

当前验证结果与正式文件校验值见[开发与验证](development.md#已验证版本)。PassGen自身源码采用[MIT](../LICENSE)，第三方许可及Slint下载页署名见[第三方声明](../THIRD-PARTY-NOTICES.md)。
