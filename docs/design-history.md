## 迭代过程

以下按会话顺序记录；编号为本文的迭代索引，不是 Figma 版本编号。

1. **确定技术路线**：选择 Rust + Slint，取代此前讨论的 C++ 方案；保留轻量跨平台与完全离线原则。
2. **建立初始设计**：参考用户提供的截图，使用白色圆角卡片、蓝色操作按钮；保留 Random 与 PIN，移除 Memorable。
3. **调整字符类型**：使用四个可多选按钮替代 switch：小写字母 (a-z)、大写字母 (A-Z)、数字 (0-9)、特殊符号 (!@#$)。
4. **增加中文界面**：保留英文版，新增中文 Random / PIN；PassGen 不翻译。
5. **增加 About**：制作中文关于页面，随后补充英文版，展示应用简介、离线隐私承诺、技术方案与目标平台。
6. **同步用户修改**：按英文 Random 的最新布局同步其他页面，隐藏外层深蓝背景、调整标题栏和卡片间距；中间曾将隐私说明放入品牌标题栏，最终移除该副标题。
7. **精简 About**：增加 Language / 语言切换，右上角返回箭头替代底部返回按钮；隐私说明改为普通文本，增加项目链接区域。所有生成器菜单统一为蓝色省略号。
8. **长度控件对齐**：加长滑块，控件间距统一为 12px，长度输入框与内容区域右侧对齐。
9. **加入导航原型**：菜单进入对应语言 About，支持 Random / PIN 切换及 About 中英文切换。About 返回箭头当前指向对应语言 Random 页面。
10. **加入模式切换动画**：Random ↔ PIN 使用 250ms Smart Animate，缓入缓出。
11. **修正顶部位移**：由于画板高度不同，预览居中时顶部会移动；统一六个画板为 800 × 879，卡片顶部固定为 40px。
12. **调整 About 动画**：先加入 Smart Animate；因过渡变暗曾临时改为即时切换，再尝试外层不透明白色背景。用户要求退回添加白色背景之前的版本。
13. **最终匹配卡片图层**：统一 About 与生成器的白色卡片名称及层级，使用同名卡片进行高度插值，替代整张卡片交叉淡化；恢复 About 进入与返回的 250ms 动画。用户随后确认基本设计可用。
14. **后续动效增强**：在上述基线上增加模式选中背景横向滑动、字符区域连续展开／收起，以及 About 内容 16px 的轻移过渡。模式切换更新为 280ms、About 进入／返回为 300ms、About 语言切换为 220ms，统一使用 `cubic-bezier(0.2, 0, 0, 1)`。已检查静态布局、图层匹配和动画配置；动态效果仍待用户预览反馈。
15. **配色方案对比**：新增独立 Figma 页「配色对比 / Color Study」（节点 `36:34`），使用同一中文 Random 布局比较当前蓝白、柔雾蓝、沉静青绿、柔和靛紫四套方案。候选主色依次为 `#315EAD`、`#0F766E`、`#5B50B5`；已核对组件文字、边框及选中底色。候选方案尚未选定，原有六个主设计与原型不变。
16. **细调稿选中态**：以用户再次调整后的柔雾蓝稿（`36:117`）为依据，为字符类型增加浅蓝底、蓝字与小勾的选中态；未选中为中性浅底、灰字、无勾。保留现有按钮尺寸与整体布局。新增本地按钮组件（`41:80`）和十五个有效多选状态（`42:323`），点击以 140ms Smart Animate 切换，最后一种字符类型不可取消。增加混合状态示例（`42:397`），已核对十五个状态与五十六条有效切换连接。该轮仅更新用户细调的候选稿，未将候选配色覆盖至原有主页面。
