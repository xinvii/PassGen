PassGen · 干净 Windows 环境人工测试清单

目标：确认在没有开发工具的普通电脑上可以使用。以下项目需人工检查，
随包的自动启动检查不等同于完成这些交互与显示测试。

环境
[ ] 记录 Windows 版本、系统架构、屏幕分辨率和缩放比例。
[ ] 电脑未安装 Rust / Cargo / Visual Studio；不为测试临时安装运行库。
[ ] 解压到带中文或空格的目录后，普通用户可双击运行。
[ ] 断网后仍能启动、生成、切换页面和正常关闭。

启动与窗口
[ ] 无既有设置时，首次窗口在主显示器居中，文字没有缺字或裁切。
[ ] 标题、图标、圆角、细边框和柔和投影正常。
[ ] 可拖动窗口，最小化、恢复和关闭正常。
[ ] 将窗口移到另一位置后关闭，重开能恢复该位置。
[ ] 最小化后从任务栏关闭，重开能恢复最小化前的正常位置。

密码生成
[ ] Random 默认20位，输入和拖动可调整至4–64位。
[ ] 鼠标在滑动条上时，滚轮每格增减1位；上下限不越界。
[ ] 四个字符按钮选中、取消正常，最后一类不能取消。
[ ] 分别只选一种字符类型，生成结果仅包含该类字符。
[ ] PIN 默认6位，可调整至4–12位，结果只有数字。
[ ] Random 和 PIN 分别记住各自长度。
[ ] 点击结果框可重新生成；悬停为浅蓝色，移开恢复白色。
[ ] 32位以上的结果完整显示，不遮挡复制按钮。
[ ] 输入空白、非数字或越界长度后，提交或失焦能恢复有效长度。

复制与键盘
[ ] 点击复制后出现“已复制”提示，粘贴结果与屏幕内容一致。
[ ] 结果展示的换行不进入复制内容。
[ ] Tab 可依次访问控件，结果框可用空格或回车重新生成。
[ ] 不复制时，应用不会自动改写剪贴板。

中英文、页面与设置
[ ] 菜单进入 About，语言切换正常，PassGen 名称不翻译。
[ ] About 返回对应语言的 Random 页面。
[ ] 切换 Random / PIN / About 时，顶部固定、不变暗、不闪烁。
[ ] 关闭后重开，语言、模式、两种长度及字符类型恢复。
[ ] 关闭后重开不恢复 About 页面、复制提示或无效输入。

显示兼容性（有条件时分别测试）
[ ] 100% 缩放。
[ ] 125% 缩放。
[ ] 150% 缩放。
[ ] 200% 缩放。
[ ] 多显示器之间拖动，尤其两个显示器使用不同缩放比例。
[ ] 在副屏关闭后断开副屏，再启动时窗口仍然可见。
